# AniManga

Одно приложение для iOS (SwiftUI, iOS 16+): каталог аниме с плеером и чтение манги.

## Что внутри

- **Аниме** — каталог, поиск, трейлеры, описания и оценки (AniList), русские названия, описания и оценки (Shikimori, переключается в настройках). Плеер на AVPlayer: mp4 / mov / HLS (m3u8), PiP, AirPlay, запоминает позицию.
  Видео в приложение не встроено: для каждой серии вы добавляете свою ссылку или файл (свой медиасервер, свои файлы).
- **Манга** — каталог и поиск (MangaDex), список глав на выбранном языке, ридер: постранично (с зумом по двойному тапу, режим справа налево) и лента-вебтун. Запоминает прочитанные главы и страницу.
- **Библиотека** — избранное, недавнее, продолжить просмотр/чтение.

## Как получить .ipa

IPA собирается только на macOS, поэтому сборка настроена в GitHub Actions:

1. Создайте пустой репозиторий на GitHub и загрузите в него содержимое этой папки.
   ```bash
   git init && git add . && git commit -m "AniManga"
   git branch -M main
   git remote add origin https://github.com/<вы>/AniManga.git
   git push -u origin main
   ```
2. Откройте вкладку **Actions** → workflow **Build IPA** (запускается сам после push, либо кнопкой *Run workflow*).
3. Через 5–10 минут скачайте артефакт **AniManga-ipa** → внутри `AniManga.ipa`.
   Если сборка упала, скачайте артефакт **build-log** и пришлите лог — исправим.
4. Хотите постоянную ссылку на IPA — создайте тег: `git tag v1.0 && git push --tags`; файл появится в **Releases**.

> Код написан без возможности скомпилировать его на Linux, поэтому первая сборка в Actions — это и есть первая проверка компилятором.

IPA получается **неподписанным**. Подпишите и установите его одним из способов:

- **Sideloadly** или **AltStore** (подпись вашим Apple ID, срок 7 дней у бесплатного аккаунта);
- **TrollStore** (если поддерживается ваша версия iOS);
- свой платный Apple Developer аккаунт — подписать через Xcode / `fastlane` / Sideloadly.

## Локальная сборка на Mac

```bash
brew install xcodegen
xcodegen generate
open AniManga.xcodeproj   # выберите свою команду подписи и запустите
```

## Структура

```
project.yml                 — описание проекта для XcodeGen
Config/Info.plist           — генерируется XcodeGen
AniManga/App                — точка входа, вкладки
AniManga/Models             — модели
AniManga/Services           — AniList, MangaDex, хранилище библиотеки
AniManga/Views              — экраны (каталоги, детали, плеер, ридер, библиотека, настройки)
.github/workflows           — сборка IPA
```
